  Feature expert manager. Manage the active and archived feature lifecycle in FEATURES.yml and spect/archive/FEATURES.yml. Do NOT use for creating or editing PRD files, creating or editing ADR files, coding tasks, git operations, CI/CD, package management, or general project architecture questions.
